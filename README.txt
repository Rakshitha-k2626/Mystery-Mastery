MYSTERY MASTERY - installable web app (PWA)
Files: index.html, manifest.webmanifest, sw.js, icons/, privacy-policy.html

1. Upload this whole folder to any HTTPS web host (Netlify, GitHub Pages, Cloudflare Pages are free).
2. Open the address on a phone: browser menu > "Install app" / "Add to Home screen".
3. For the Play Store, give the live address to PWABuilder (pwabuilder.com) to generate an Android package,
   or wrap the folder with Capacitor.
4. Fill in [DATE] and [YOUR EMAIL] in privacy-policy.html and host it; the stores ask for its web address.
5. Replace the placeholder "?" icon with your own artwork (192x192 and 512x512 PNG).
